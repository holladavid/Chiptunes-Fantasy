# GitHub Pull Request — v1.6.4

## Pull Request Title

```text
Chiptunes Fantasy v1.6.4 — Split/Museum/Chip Workspace, Story-First Dossier UI & Cross-System Library Reorganization
```

## Summary

This release introduces a **3-mode right-panel workspace (`[ SPLIT ]` / `[ MUSEUM ]` / `[ CHIP ]`)**, **`[ TRACK STORY ]` / `[ HARDWARE ]` museum sub-tabs**, a **story-first 2-column dossier layout**, **`1900px+` 3-column Command Deck support**, and **`MUSEUM ↗` scroller cross-linking**, while completing a comprehensive **directory reorganization, chronological curation, and museum metadata rewrite** across C64 (now 57 entries), Amiga (73 tracks), and Atari ST (86 tracks).

## Changes

### 1. Workspace Modes, Museum Sub-Tabs & Story-First Desktop Layout (`index.html`, `css/style.css`, `js/app.js`, `js/visuals/visualizer.js`)

- **3-mode workspace selector:** Replaced `#btn-toggle-archive` (`[ HIDE CHIP ]`) with `.workspace-mode-group` (`[ SPLIT ]`, `[ MUSEUM ]` with `A` keyshortcut, `[ CHIP ]`) in `.living-silicon-toolbar`, backed by `setRightPanelMode()` (`body.dataset.rightMode`, `body.archive-expanded`, `body.chip-expanded`).
- **Museum sub-tabs & dossier view:** Added `[ TRACK STORY ]` and `[ HARDWARE ]` sub-tabs in `.museum-archive-toolbar` (`setMuseumTab()`, `renderMuseumContent()`), rendering a 2-column `.museum-story-dossier` with collapsible `> BINARY ANALYSIS` and cross-link jump buttons (`data-jump-museum-tab`), preserving the active sub-tab on HIPC subsong switches (`preserveMuseumTab`), and resetting to `hardware` on system switches.
- **Overflow hint & chip-expand layout:** Added clickable `#btn-museum-expand` trigger (`[ EXPAND ]` / `[ SPLIT ]`), sticky `#museum-scroll-hint` (`[ ↓ FULL MUSEUM (A) ]`) in Split mode (`updateMuseumScrollHint()`), expanded `.silicon-chassis` sizing in `chip-expanded` mode, and skipped `siliconVisualizerInstance.update()` in `js/visuals/visualizer.js` when `archive-expanded` hides Living Silicon.
- **Desktop proportions & verification meta:** Lowered the 3-column Command Deck media query from `2200px` to `1900px`, adjusted `#demo-container` vertical proportions, hid `.silicon-diagnostics` at `1900px–2199px` in Split mode to protect Paula/YM2149F layout width, tuned C64/Amiga/Atari museum typography, and added the Google site-verification meta tag in `index.html`.

### 2. Semantic Hardware Dossier Markup (`js/content/museum.js`, `css/style.css`)

- Replaced inline CSS styles in `systemDescriptions` (`c64`, `amiga`, `atari`) with semantic HTML (`<section>`, `<dl>`/`<dt>`/`<dd>`, `<article>`) and dedicated classes (`.museum-hardware-dossier`, `.museum-spec-card`, `.museum-spec-title`, `.museum-spec-grid`, `.museum-essay`).

### 3. Scroller-to-Museum Cross-Linking & Delimiter Fix (`js/visuals/scroller.js`, `js/app.js`, `index.html`, `css/style.css`)

- Added `#scroller-open-museum` (`MUSEUM ↗`) in `#scroller-zone` wired through `initScroller(..., { onOpenMuseum })` to open the active track's museum dossier (with mobile smooth scroll to `.museum-archive-toolbar`) and updated mobile `.scroller-actions` to dynamic `grid-auto-flow: column`.
- Fixed `museumStory()` in `js/visuals/scroller.js` so excerpts stop cleanly before `SID & Replay:`, `Technik & Replay:`, `YM2149 & Replay:`, and `Datei & Replay:`.

### 4. C64 Library Reorganization, New Additions & Museum Rewrite (`tracks/c64/`, `js/content/songlengths.js`)

- Consolidated `tracks/c64/` into `games/`, `musicdisks/`, `demoscene/`, and `tests/` using kebab-case paths and a single chronological `c64Tracks` registry in `tracks/c64/playlist.js` (removing `tracks/c64/assembly/provenance.json` and `tracks/c64/classics/provenance.json`).
- Added Rob Hubbard's original `Delta.sid` and Martin Galway's `Ocean_Loader_1.sid` (expanding C64 to 57 entries: 56 tracks + 1 test suite); moved Tomas Danko's *Delta* reinterpretation to `demoscene/delta-tomas-danko.sid`; fixed swapped `radio-napalm.sid` <-> `coma-light-13-tune-1.sid` files and `songlengths.js` entries; renamed `musicdisks/compilation-iii.sid` and `demoscene/comaland-100-facetime.sid`; moved `SID_Emulation_Test.sid` to `tests/sid-emulation-test.sid`.
- Rewrote `tracks/c64/museum.js` with SID hardware/driver details and direct DeepSID/CSDb/Demozoo references.

### 5. Amiga Library Reorganization & Museum Rewrite (`tracks/amiga/`, `doc/implementation-plans/`)

- Consolidated `tracks/amiga/` into `games/` (with `amberstar/`, `dragonflight/`, `giana-sisters/`, `wings-of-death/`), `demoscene/`, and `tracker-xm/` (`deadlock.xm`, `space-debris.xm`, `turrican-2-title.xm`); moved `hipc.samp` to `games/amberstar/hipc.samp`.
- Refactored `tracks/amiga/playlist.js` to a single chronological `amigaTracks` registry with explicit `sampleBank`, `envSpec`, and `format: 'hip68k'` flags; removed unplayable `beast1.title.dw`, `tracks/amiga/classics/provenance.json`, and unused `dw-parser.js` import.
- Rewrote all 73 `tracks/amiga/museum.js` entries and added Wave 2 playlist expansion implementation plans (`doc/implementation-plans/Amiga-playlist-expansion-wave2.md`, `doc/implementation-plans/C64-playlist-expansion-wave2.md`).

### 6. Atari ST Library Reorganization & Museum Extraction (`tracks/atari/`)

- Consolidated `tracks/atari/` into `games/` and `demoscene/` with unified kebab-case filenames; moved `spherical-intro.ym` to `games/`, reunited *Stormlord* under `games/stormlord/`, moved *Punish Your Machine* to `demoscene/`, fixed `UndionDemo_ThinkTwice.YM` (`demoscene/union-demo/loader.ym`), and removed `Captain_Blood.sndh` and `tracks/atari/SOURCES.md`.
- Extracted all 86 inline descriptions from `tracks/atari/playlist.js` into `tracks/atari/museum.js` with YM2149/MFP/SainT hardware notes and individualized *Amberstar*, *Wings of Death*, *Lethal Xcess*, and *Union Demo* entries, removing virtual `path`/`sourcePath` discrepancies.
