# GitHub Release Description

**Von Nerds für Nerds:** v1.5.4 completes the six-stage Amiga Exact refinement program, expands the music disk with **48 researched classics**, stabilizes the C64 environmental instruments, and restores Atari YM5 Digidrum starts. The curated collection now contains **205 directly playable tracks**: **69 Amiga**, **50 C64**, and **86 Atari ST** titles.

No MP3s or prerecorded audio are used. Historical binary music formats are parsed and synthesized in real time. Exact remains a bounded software model, not a claim of universal physical-chip or mainboard equivalence.

## Highlights

- **Amiga Exact, phases 0–5:** reproducible measurement, corrected Paula state and reset behavior, PAL CIA replay timing, HIP68K raster scheduling, expanded MOD/XM semantics, a linear A500 approximation, and state-preserving pause/resume.
- **69-track Amiga library:** all 45 existing entries plus 24 game/demo classics, with individual museum research and hash-bound provenance.
- **50-track C64 library:** all 26 existing paths plus 24 HVSC #85 selections, individual museum cards, official sub-song lengths, and production folder navigation.
- **Stable C64 environmental diagnostics:** no random jitter, no bus-rate value averaged as a fourth audio channel, and refresh-rate-independent smoothing.
- **Atari YM5 Digidrum repair:** version-specific R3 normalization fixes eight affected YM5 tracks without changing global YM6 decoding.
- **Library-wide evidence:** 69/69 Amiga and 50/50 C64 tracks pass deterministic offline acceptance; representative production playback is also exercised in Chromium.

## Amiga Exact: six bounded refinement stages

### Phase 0 — measurement before modification

A real-production-worklet harness exposes separate `paula`, `zoh`, and `a500` signal taps. The corpus inventory records file hashes, formats, channels, durations, tracker effects, pattern features, sample properties, and COSO/HIP structures. Missing required fixtures fail instead of becoming silent skips, and ambiguous parser findings remain reference-required rather than being declared defects without evidence.

### Phase 1 — digital Paula state and complete restart

`AUDxVOL = 0` now affects only the DAC multiplier. Active DMA, period counters, byte phase, pointers, and loop state continue while the channel is silent, so restoring volume no longer resumes from the wrong sample position.

`PLAY_TRACK` resets all logical and hardware channels together with sequencer, replay, tracker-effect, filter, FIR, and visualization state. COSO/HIPC, HIP68K, MOD, and XM restart bit-identically to fresh worklets, including a format-change case.

### Phase 2 — PAL CIA timing and HIP68K raster events

COSO/HIPC and HIP68K share the documented timing source:

```text
PAL Paula clock   = 3546895 Hz
PAL CIA clock     = 3546895 / 5 = 709379 Hz
CIA timer period  = 14188
Replay tick       = 709379 / 14188 = 49.99851987595151 Hz
```

HIP68K places its documented DMA start after three raster lines and loop LC/LEN writes after a fourth, rather than collapsing all register activity onto the tick boundary. This is targeted replay scheduling, not a claim of complete cycle-accurate 68000 bus emulation.

### Phase 3 — MOD/XM playback semantics

The Exact sequencer now advances continuous effects after tick zero, including arpeggio, portamento, tone-portamento, vibrato, tremolo, volume slides, combined effects, and effect memory. It also handles linear XM frequencies, sample offset, XM panning, global volume, variable pattern lengths, and the existing 16/24/32-channel attenuation.

This is targeted MOD/XM replay, not a complete FastTracker II instrument engine. Instrument envelopes, keymaps, auto-vibrato, and unverified special commands are not presented as fully implemented.

### Phase 4 — linear A500 output approximation

The uncalibrated LF347/`tanh` stage and second `tanh` saturation were removed from Exact. The retained output model consists of the documented 4.421 kHz one-pole RC filter, optional 3.09 kHz Butterworth LED filter, 255-tap FIR, and 0.7 output scale. LED-filter history now advances continuously in bypass, preventing stale state when the filter is re-enabled.

These filters remain declared software approximations, not a measured Amiga-mainboard calibration.

### Phase 5 — production state, performance, and browser integration

Pause now freezes playback without destroying DMA, sample, sequencer, effect, replay, or filter state. Resume continues bit-identically to an uninterrupted reference for COSO/HIPC, HIP68K, MOD, and XM.

The production acceptance covers representative sample rates, long deterministic renders, heap stability, real browser AudioWorklet integration, Master DSP, the Amiga LED-filter control, and desktop/mobile-viewport UI flows. Offline timing and headless browser results are not guarantees against underruns on every physical device.

## Curated Amiga library: 69 tracks and 24 additions

The Amiga playlist preserves all 45 existing paths and adds 24 Modland modules: 12 game selections and 12 demo-scene selections. The resulting format distribution is **35 HIPC-family, 31 MOD, and 3 XM** entries.

New highlights include music associated with *Cannon Fodder*, *The Chaos Engine*, *Speedball 2*, *Gods*, *Pinball Dreams*, *Pinball Fantasies*, *Project-X*, *Superfrog*, *Lemmings*, *Another World*, *Dune*, and *Shadow of the Beast*, alongside demo-scene works such as *Red Sector Theme*, *Trans Atlantic*, *Cream of the Earth*, *Occ-San-Geen*, and *Obvious Disaster*.

Nested game/demo folders make the collection browsable. Museum entries distinguish researched history from facts measured in the supplied local file; a MOD or XM conversion is not described as the game's original replay format. Existing credits and claims were reviewed, including *Agony*, *Elysium*, *Space Debris*, *Guitar Slinger*, *Turrican II*, *Wings of Death*, and *Dead Lock*.

`tracks/amiga/classics/provenance.json` binds each new file to its original archive URL, byte size, and SHA-256. `doc/museum/amiga-track-sources.md` records selection, research, editorial corrections, and rights boundaries.

## Curated C64 library: 50 tracks and 24 additions

The C64 playlist retains all 26 existing paths and adds 24 files from **High Voltage SID Collection #85**: 20 game soundtracks and four demo-scene works. New selections include *Ocean Loader 2–4*, *Parallax*, *Lazy Jones*, *Ghouls ’n’ Ghosts*, *Katakis*, *Turrican*, *Armalyte*, *Last Ninja 3*, *Flimbo’s Quest*, *Radio Napalm*, *Edge of Disgrace*, and *Comaland 100%*.

Every one of the 50 entries now has an individual museum card with history, local SID/replay observations, and source links. Editorial corrections include Tomas Danko's *Delta* interpretation, the embedded *Compilation III* title in `Compilation_II.sid`, the 1986 *Comic Bakery* date, separated *Mega Apocalypse* credits, and differentiated *Turrican* authorship.

Official HVSC #85 sub-song lengths are assigned through 43 direct MD5 matches and seven unique path-based legacy mappings. The local Rambo variant has 23 sub-songs; only the first 23 lengths from the current 24-entry HVSC record are used, without replacing the local binary. C64 folder navigation is enabled in the production interface so the new game/demo directories are actually reachable.

`tracks/c64/classics/provenance.json` records origin, hashes, byte sizes, header fields, compatibility flags, sub-song counts, and lengths. `doc/museum/c64-track-sources.md` documents research and editorial decisions.

## C64 environmental diagnostics

The environmental presentation model no longer treats the fourth C64 telemetry slot—the SID bus-rate value—as another channel loudness value. Random jitter was removed, and smoothing now depends on elapsed time rather than display frame rate. Invalid telemetry is contained and reset behavior is covered by tests.

This is a diagnostics/UI correction only; SID synthesis and replay behavior were not retuned.

## Atari YM5 Digidrums

YM5 frames now receive a version-specific normalization before the shared effect decoder. For YM5, R3 bits 4–5 select Digidrum starts on voices A/B/C; R1 remains untouched because it belongs to Timer Synth in this format. Global YM6 decoding is unchanged.

A regression test uses real *Punish Your Machine* frame 2307. After YM5 normalization, R3 `0x31` starts sample 0 as a Digidrum on voice C.

The library audit covers 20 sample-based tracks:

- eight affected YM5 tracks are repaired by the normalization;
- eleven YM6 tracks retain their already-correct decoding;
- *Turrican 1* contains sample blocks but no Digidrum start commands, so embedded sample data alone is not treated as a playback defect.

## Validation

- **Full suite:** **361 tests — 353 passed, 7 skipped, 1 known pre-existing failure**. The suite is therefore not reported as completely green.
- **Amiga curated corpus:** **69/69 passed**. Every track was rendered with standard blocks, repetition, irregular block sizes, and restart; all outputs were audible in the measurement window, finite, deterministic, block-size-independent, and restart-identical. No silent A500 title was found.
- **Amiga focused production evidence:** the Phase 5 report records 213/213 focused Amiga/replay tests, representative 44.1/48/96 kHz cases, long deterministic renders, heap stability, and 16 passing Chromium engine runs at 44.1/48 kHz across desktop and mobile viewports.
- **C64 curated corpus:** **50/50 passed** the equivalent four-render production-worklet acceptance at 48 kHz. No silent or non-finite tracks were found; repeated, irregular-block, and restart renders were bit-identical.
- **C64 browser acceptance:** desktop and mobile-viewport Chromium checks exercised folders, museum cards, safe source links, and real playback of *Ocean Loader 2*, *Comaland 100%*, and *Commando*, without console, dialog, request, or HTTP errors.
- **Atari regression:** the real YM5 Punish-frame test proves sample 0 starts on voice C for normalized R3 `0x31`; the sample audit explicitly separates corrected YM5 files from unchanged YM6 files.

The single full-suite failure remains `SID synthetic corpus matches the reviewed Phase 3 raw/trace/WAV hashes`. For `noise-adsr`, the actual hash remains `d26ae30f7221b719eb6dfdebb5b77b7ed5f841662c28ab7d9943a5e522d93ff0`; the previous baseline was not overwritten. See `doc/verification/c64/curation-report.md` for the complete record.

## Known limitations

- The pre-existing SID synthetic-corpus mismatch remains open; no baseline or emulator path was changed to conceal it.
- Amiga A500 RC/LED values are software approximations. No supplied hardware or UADE reference WAVs were available for a new external sound/level acceptance, and self-generated hashes are regression anchors rather than hardware truth references.
- Amiga MOD/XM support is not a complete FastTracker II instrument/envelope implementation; unverified replay features remain outside the claim.
- Atari `ym-exact` remains a fixed-2-MHz register-dump player. It does not provide complete MC68000/MFP/SNDH replay, Atari-STE DMA audio, or arbitrary non-2-MHz production playback. YM DAC/mainboard calibration remains future measurement work.
- C64/SID random-access seeking remains unavailable.
- Offline real-time ratios include analysis overhead and are not device underrun guarantees. Headless Chromium mobile viewports are not physical phones, and no controlled reference-device listening test is claimed.
- Background playback remains subject to browser, mobile OS, and power-management policy.
- Public availability in Modland or HVSC does not imply public domain, redistribution permission, or commercial-use rights. Rights remain with their respective holders.

```bash
npx serve .
# or
python3 -m http.server 8080
```

Open the shown local URL, enter through the boot screen, and select **AMIGA**, **COMMODORE 64**, or **ATARI ST**. Use the curated folders to browse game and demo-scene selections.
