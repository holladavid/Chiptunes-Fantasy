## Pull Request Description

## Summary

This release expands the synchronized castle scenes across Amiga, Atari ST, and C64, and refines the Paula silicon output-stage visualization.

- Adds `AmigaCastleFireworks`, an Amiga-only background DSE with an OCS-quantized palette and beat-responsive castle, fireworks, and atmospheric choreography.
- Reimagines `AtariEnchantedCastle` as a dark gothic storm scene using a strict 16-color Atari ST palette and precomputed ridge geometry.
- Refines the C64 Castle Fireworks architecture and shoreline, with visual choreography driven by beat strength and musical tension.
- Compacts the Paula output-stage filter response windows and simplifies the FIFO status labels.
- Adds focused Amiga and Atari castle tests and retains system-specific background registration.

## Changes

### 1. Amiga Castle Fireworks

- Adds `AmigaCastleFireworks` to the registry exclusively as an Amiga background.
- Builds a Gothic citadel landscape with a moonlit loch, stone viaduct, and reflected scenery.
- Uses a bounded palette quantized through the shared Amiga 12-bit color helper.
- Drives fireworks, lightning, rim lighting, and other scene accents from beat strength, beat level, and musical tension.
- Adds checks for palette quantization, integer-pixel drawing, valid viewport geometry, beat-event handling, and registry metadata.

### 2. Atari Enchanted Castle

- Reworks `AtariEnchantedCastle` as a dark gothic castle and storm scene, registered exclusively for Atari ST.
- Enforces the Atari ST 9-bit Shifter color steps and a maximum 16-color palette.
- Precomputes ridge geometry and bounds particle/burst pools.
- Adds beat-graded magic and storm choreography with tests for color, geometry, viewport bounds, beat handling, and pool limits.

### 3. C64 Castle Fireworks

- Refines the castle roof contours, pixel alignment, and water reflections.
- Adds beat-strength and tension-aware scene choreography while retaining exact beat events for discrete triggers.
- Keeps the DSE registered only for C64 background use.

### 4. Paula silicon visualization

- Moves and narrows the filter-response display windows to fit the output-stage diagram.
- Shortens the FIFO status text for standby and active fetch states.
- Preserves the underlying Paula state reporting and output-stage behavior.
