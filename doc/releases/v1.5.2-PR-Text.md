# Pull Request Title

**feat(release): refine Exact SID telemetry and Living Silicon for v1.5.2**

# Pull Request Description

## Summary

This release-candidate PR completes Chiptunes Fantasy v1.5.2 with a telemetry-driven C64 Living Silicon instrument and bounded Exact-SID corrections validated against original music binaries and a supplied original-C64 recording.

The headline feature is a demoscene-style **SID Activity** meter. It visualizes meaningful, separately labelled quantities instead of an undefined “SID load” percentage:

- normalized envelope activity for voices 1–3;
- GATE state and actual internal ADSR phase;
- true SID register writes per second, including repeated writes of an unchanged value;
- independent `$D418` activity and a logarithmic 48-column bus-history display.

The PR also includes the Exact refinements developed after v1.5.1: original-recording-backed rising-GATE rate-phase behavior for *Wizball*, the measured `$50` triangle-plus-pulse transfer used by *The Great Giana Sisters*, and display timing independent of arbitrary SID play-call rates.

## Changes

### 1. Living Silicon SID Activity instrument

- Adds three 16-segment envelope meters with GATE indicators, 250 ms peak holds, and actual ADSR states.
- Adds a monotonic register-write counter to both C64 chip implementations; the counter is telemetry-only and is never read by synthesis.
- Reports writes/second from the existing reusable worklet visual buffer and displays them on a bounded logarithmic scale.
- Counts repeated same-value writes and multiple writes between display frames, which snapshot-only bus diffing could not represent.
- Adds a 48-entry preallocated bus-history ring and independent `$D418` activity indication.
- Keeps voice activity, register traffic, output loudness, and CPU utilization semantically separate.
- Adds a responsive instrument rail that remains visible on desktop, laptop, and mobile layouts.
- Distinguishes **MOS 6581 R3 Exact** from **SID Fantasy Studio** in the panel title and replaces static measurement-like labels with explicit model terminology.
- Uses preallocated meter arrays, primitive numeric state, dirty-checked DOM updates, and a slower text-update lane.

### 2. Exact ADSR behavior validated against the supplied Wizball recording

- Restarts the 15-bit envelope rate phase on a resolved rising GATE.
- Resets the exponential divider and clears zero hold on that attack.
- Preserves running counters on Release; `TEST` does not restart the attack phase.
- Retains the zero-level underflow guard that prevents non-finite audio for short GATE pulses.
- Keeps the two-clock GATE pipeline, exact period matching, 15-bit wraparound, linear Attack, and exponential Decay/Release behavior.

Evidence is deliberately bounded to the supplied original-C64 *Wizball* high-score recording, Subsong 7. In the examined 5.5–10.5-second passage, all 21 short voice-2 attacks reach envelope 255 after the correction; previously, 20 remained at 0 or 1. This is not a claim that every ADSR property, every 6581 revision, or every other emulator has been validated.

### 3. Giana `$50` triangle-plus-pulse calibration

- Adds an independently measured 257-anchor, phase-indexed 12-bit transfer model for MOS 6581 R3 selector `$50`.
- Uses prepared typed-array anchors and primitive interpolation in the audio hot path.
- Special-cases `$50` before generic wired-AND; other combined selectors retain their existing baseline.
- Restores the examined Exact-path “angel voice” passage in *The Great Giana Sisters* Subsong 2 without converting Fantasy into an Exact hardware path.

### 4. Display-only timeline correction

- Advances displayed C64 time from an independent 50 Hz accumulator.
- Leaves CPU/CIA dispatch, music play-call rates, audio rendering, and subsong behavior unchanged.

## Scope and boundaries

- No MP3 or prerecorded-audio playback was introduced.
- No reSIDfp/VICE implementation code or internal tables were imported.
- Exact remains targeted at MOS 6581 R3; hardware-oriented CSG 8580 remains separate future work.
- Fantasy remains an artistic stereo studio interpretation.
- The v1.5.2 meter changes do not alter oscillator, envelope, filter, mixer, resampling, or CPU/CIA algorithms.
- The original-recording calibration and other measured corrections support the examined passages; they do not establish universal physical-chip authenticity.
