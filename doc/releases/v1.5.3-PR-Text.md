# Pull Request Title

**feat(atari): complete YM2149 Exact and curated library for v1.5.3**

# Pull Request Description

## Summary

This release PR completes Chiptunes Fantasy v1.5.3 with a measured and deterministic Atari-ST/YM2149 Exact path, a substantially expanded and curated YM library, and a dedicated technical deep dive.

The hardware-oriented work fixes reproducible digital and transport issues without retuning the artistic Atari cores or unrelated C64/Amiga DSP. The curated library grows from 73 to **86 directly playable tracks**, adds **13 highlights**, introduces nested game/demo folders, and replaces generic or unsupported museum claims with reviewed metadata and editorial context.

## Changes

### 1. Deterministic YM2149 digital core and measurement harness

- Adds a raw offline harness with cycle-stamped register events, stable same-cycle write ordering, preallocated state traces, CSV export, and deterministic IEEE-float32 WAV output.
- Advances tone, noise, envelope, DAC selection, and mixing through `YM2149Core.clockCycle()` on the 2 MHz YM timeline.
- Corrects R13 envelope startup: falling shapes begin at level 31, rising shapes at level 0, and the first step retains its full duration. R13 `$FF` preserves the running envelope state.
- Maps fixed volume zero to silence and other nonzero fixed values to the 5-bit DAC domain.
- Makes track restart bit-identical to a fresh worklet and clears digital, effect, resampler, filter, fade, and display state on track changes.
- Preserves digital and transport state across stop/resume.

### 2. YM6 effects with MFP-derived timing

- Decodes two independent effect slots instead of treating R14/R15 as generic Digidrum triggers.
- Implements Digidrum, SID-Voice, Sinus-SID, and Sync-Buzzer behavior.
- Uses `2457600 / predivisor / timerCount` with integer phase accumulation on the 2 MHz YM timeline.
- Preserves phase for unchanged continuous effects, retriggers repeated Digidrum commands, and restores current register levels when effects finish.
- Routes sample and effect levels through the selected YM voice/DAC path rather than inventing a native YM2149 PCM channel.

### 3. YM formats, loops, and transport integration

- Supports YM3!, YM3b, YM5!, and YM6! data with validated headers, register layouts, metadata strings, sample ranges, and end markers.
- Corrects YM3's 14-register frame layout and YM3b's stored loop frame.
- Handles interleaved and frame-serial YM5/YM6 register dumps plus signed, unsigned, and already-4-bit Digidrum encodings.
- Uses parsed `playerRate` and `loopFrame` consistently for playback, seeking, UI duration, and Media Session position.
- Documents the current production boundary: `ym-exact` remains fixed at 2 MHz and is a register-dump player, not an MC68000/MFP/SNDH emulator.

### 4. Linear output and measured two-stage resampling

- Sums the three YM voices linearly with one fixed level-preserving scale.
- Removes the former additional bus compression and `tanh` saturation from the Exact path.
- Replaces the previous output chain with two cascaded 256-phase Kaiser-windowed-sinc stages, an intermediate rate of four times the host rate, a 20 kHz requested passband, and a 96 dB design target.
- Retains the declared linear 15.9 kHz low-pass and 25 Hz high-pass output model without claiming physical-mainboard calibration.
- Caches register-derived periods and fixed levels on writes and unrolls the mono FIR loop without changing accumulation order.

| Output rate | Stage taps | Constant group delay | Worst stopband-start response |
|---:|---:|---:|---:|
| 44.1 kHz | 181 + 493 | 1.439558 ms | −99.463 dB |
| 48 kHz | 163 + 297 | 0.811333 ms | −102.999 dB |
| 96 kHz | 73 + 87 | 0.129979 ms | −98.939 dB |

### 5. Curated 86-track Atari library

- Adds 13 YM highlights from *Ghouls ’n Ghosts*, *Speedball*, *Stormlord*, *Chambers of Shaolin*, *Xenon 2 – Megablast*, *LED Storm*, *Synergy*, and *Punish Your Machine*.
- Introduces nested logical folders for games and demo-scene productions while preserving every existing physical source path and production-baseline path.
- Adds concise `listTitle` labels for browsing without shortening full museum titles.
- Redacts and expands museum texts for the complete collection.
- Corrects Xenon track roles and the *Syntax Terror* composer credit; replaces invented Amberstar, *Wings of Death*, and *Lethal Xcess* scene/level names with defensible archive numbering.
- Removes unsupported DSP, stereo, phase, and hardware-superlative claims.
- Documents all new source archives, inner filenames, LH5 unpacking, metadata provenance, and rights boundaries in `tracks/atari/SOURCES.md`.

### 6. Atari ST Technical Deep Dive

Adds `doc/specs/emulation/atari/technical-deep-dive-atari.md` and links it from the README. The document covers:

- parser and transport architecture;
- the 2 MHz tone/noise/envelope core;
- YM6 effect descriptors and MFP-derived timing;
- DAC mapping and linear summing;
- two-stage resampling and output filtering;
- reset, pause, and seek semantics;
- offline measurement, performance, alternative cores, and evidence boundaries.

It explicitly distinguishes implemented digital behavior, measured software/filter properties, and open physical-hardware calibration.

## Scope and boundaries

- No MP3 or prerecorded-audio playback was introduced.
- No full MC68000, MFP, or SNDH replay environment is claimed.
- No Atari-STE DMA audio or stereo extension is added.
- Artistic `ym-fantasy`, `ym-bladerunner`, and lightweight `ym-standard` behavior is not presented as Exact hardware behavior.
- Self-generated hashes remain regression anchors, not hardware truth references.
- No real YM2149 DAC or Atari-mainboard calibration is claimed.
- Existing physical YM paths were not moved, and no production baselines were overwritten during library curation.
