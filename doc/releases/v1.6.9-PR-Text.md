## Summary

Version 1.6.9 adds a new **`EMULATION & TIMING`** calibration category to `DisplaySetupDialog` (selectable DSE VBL refresh divisors `50 / 25 / 16.7 / 12.5 Hz`, `SLOW / NORM / FAST` Tension buildup speed, restored C64 `SID TEMP` `15–75 °C` thermal control, and a live `LIMIT BAR` toggle), expands the desktop calibration deck to a 3-column rack with proportional button sizing, introduces **`GPU: OFF`** plus optical and `DELTA` alignment fixes in `CrtShadowMask`, extends stage overlay auto-hiding (`user-inactive`) to windowed mode with touch wake protection, overhauls **`LimitBar`** to `v4.0.0` (Demoscene Hardware Edition) in full compliance with `DSE-Entwicklungsregeln.md`, and normalizes `tracks/c64/games/ocean-loader-1.sid`.

## Changes

### 1. Stage Overlay Auto-Hide in Windowed Mode (`css/style.css`, `js/app.js`)

- Updated `#visual-zone.user-inactive` rules in `css/style.css` so `#brand-logo` and `#fs-ui-bar` fade out after `3 s` of inactivity in windowed mode alongside `#chip-hud.collapsed` and `#now-playing`, removing both desktop and mobile `:not(:fullscreen)` overrides.
- Explicitly set `pointer-events: none` on `.now-playing-progress[data-seekable="true"]` and `.fs-progress-bar[data-seekable="true"]` while `.user-inactive` or `.overlays-waking` is active.
- Added an `overlays-waking` touch wake-up guard (`clearOverlayWakeGuard`, `450 ms` fallback, `80 ms` after `touchend`/`touchcancel`) in `js/app.js` so the first tap reveals controls without triggering hidden buttons underneath.
- Triggered `resetMouseIdleTimer()` at the end of `setTheme()` so stage overlays appear briefly on boot and system switches before fading out.

### 2. WebGL CRT Shadow Mask: `GPU: OFF` & Optical Realism (`js/visuals/components/crt-shadow-mask.js`, `js/visuals/visualizer.js`, `js/visuals/display-settings.js`)

- Added `'off'` to `CRT_QUALITIES` in `display-settings.js` and `QUALITY_LEVELS.off = -1` in `crt-shadow-mask.js`.
- Updated `CrtShadowMask.releaseResources()`, `initialize()`, `resize()`, and `render()` to skip shader compilation, FBO/texture allocation, and per-frame texture uploads when `quality === 'off'`, freeing GPU resources on toggle.
- Decoupled WebGL capability (`isCrtWebglAvailable` / `displaySettings.setCrtAvailable`) from active shader rendering (`syncCrtMaskVisibility`) in `visualizer.js` so `GPU: OFF` drops `.crt-mask-active` (falling back cleanly to `#demo-canvas` + CSS `.scanlines`) while keeping `GPU` controls and `A/B` compare active.
- Fixed `DELTA` triad quantization (`step = 2`, `minTriad = 4`, `rowPitch = triad / 2`) so `MASK PITCH` responds on `DPR = 1` screens without Moiré, and aligned `DELTA` scanline phase directly onto phosphor dot rows (`1X`) and across dot pairs (`2X`).
- Upgraded `QUALITY >= 1` beam filtering to a center-weighted 3-tap Gaussian (`0.5 * center + 0.25 * sides`, clamped to `1.5 px` in `MED`/`HIGH`, `0.5 px` in `LOW`) to eliminate double contours on HiDPI displays.
- Added energy-preserving scanline spot-blooming (`wLow` / `wHigh` with exact `meanWave` normalization), widened the glow prefilter to `0.375` overlapping tent taps with HiDPI tap-spacing scaling, and compiled the active `maskType` via `#define MASK_TYPE` (recompiling on `quality` or `maskType` changes in `setOptions()`).

### 3. `EMULATION & TIMING` Calibration Deck & Layout Fixes (`js/ui/display-setup-dialog.js`, `js/visuals/display-settings.js`, `css/style.css`, `js/app.js`)

- Added persisted `EMU_DEFAULTS` (`dseRefreshDivisor: 1`, `tensionSpeed: 'normal'`, `sidTemperature: 55`, `showLimitBar: false`) and `sanitizeEmuSettings()`, `getEffectiveEmu()`, `updateEmu()`, and `resetEmu()` to `DisplaySettingsStore`.
- Added the `EMULATION & TIMING` section (`> EMULATION & TIMING`, `[ EMULATION ]` tab, renamed scope tab to `[ SCOPE ]`) to `DisplaySetupDialog`:
  - `DSE RATE (HZ)`: `50 | 25 | 16.7 | 12.5`
  - `TENSION`: `SLOW | NORM | FAST`
  - `LIMIT BAR`: `OFF | ON`
  - `SID TEMP`: `15 °C – 75 °C` (`C64 ONLY` disabled state on Amiga/Atari ST)
  - CRT `[ SHADER OFF · CSS ]` badge and locking of shader-only CRT presets/switches/sliders while `GPU: OFF` is selected.
- Wired `applySidTemperature()` in `js/app.js` on C64 core boot, `core-selector` switching, and `displaySettings` `'emu'` / `'bypass'` / `'reset'` notifications.
- Updated `css/style.css`: expanded `.display-setup-dialog` (`1460 px`, `1560 px` at `>= 2200 px`), added 3-column rack layout at `>= 1360 px` (tabs retained at `1050–1359 px` with ellipsis protection), switched `.setup-seg-btn` from `flex: 1 1 0` to `flex: 1 1 auto`, added `.setup-segment-group-wide` full-row layout for `PHOSPHOR` & `DSE RATE (HZ)`, and balanced CRT/EMU segment column proportions (`1.15fr / 0.72fr / 1.25fr` and `1.2fr / 0.8fr`).

### 4. DJ Engine Throttling, Tension Speed & Permanent Overlay Routing (`js/visuals/scene-dj.js`, `js/visuals/dj/stage-manager.js`, `js/visuals/dj/tension-manager.js`, `js/visuals/dj/setlist-manager.js`, `js/visuals/visualizer.js`)

- Added `StageManager.setRefreshDivisor()` to throttle DSE rendering to `50 / divisor` Hz while preserving beat-latching across cached frames and invalidating caches on rate changes.
- Added `TensionManager.setSpeedMode()` with `TENSION_SPEED_PROFILES` (`slow`, `normal`, `fast`) scaling both accumulation rate and `buildupHoldTime`.
- Added `SetlistManager.setPermanentDseEnabled()` and updated `fillEmptyLayers()` so enabled permanent overlays (`LimitBar`) mount on `'overlay'` independently of `oneshot` `TrackPresenter` banners.
- Added `SceneDJ.setOptions()` and cloned `entry.metadata` per `SceneDJ` instance in `visualizer.js` (`wireSiliconDJ()`) so runtime `LimitBar` toggling never mutates `dseRegistry`.

### 5. `LimitBar` v4.0.0 Overhaul & Track Rename (`js/visuals/dse/universal/limit-bar.js`, `tracks/c64/games/ocean-loader-1.sid`)

- Rewrote `LimitBar` with zero per-frame allocations, precomputed C64/Amiga/Atari palette LUTs, deterministic `hashU32` timing, `dt`-based slide transitions (plus immediate active onset rendering for `warmup: 0`), `beatStarted`-gated discrete phase updates, dark contrast bezels, and strict `[0..width, 0..height]` bounds clipping (`fillClampedRect` + `drawAliasedLineClipped`).
- Implemented system-authentic effects:
  - **C64:** VIC-II `$D020/$D021` scanline rasterbars, 3 physical SID voice LEDs (`smooth[0..2]`), and 2×1 beveled Colodore segments.
  - **Amiga:** 64-step 12-bit OCS Copperlist LUTs with Extra Half-Brite (EHB) lower shading, L-R-R-L 4-channel Paula DMA pips (`smooth[0..3]`), stepped blitter sweeps, and `climax` end-cap orbiters.
  - **Atari ST:** Strict 9-bit Shifter palette (`<= #fcfcfc`), Timer-B bezel split pulses, 3 YM2149 voice pips (`smooth[0..2]`), and clipped tip/edge Bresenham sparks.
- Renamed `tracks/c64/games/Ocean_Loader_1.sid` → `tracks/c64/games/ocean-loader-1.sid`.
