# Pull Request Title

**feat: release v1.5.5 with Giana Sisters and adaptive scroller**

# Pull Request Description

## Summary

Chiptunes Fantasy v1.5.5 adds four verified Amiga ProTracker conversions from *The Great Giana Sisters* and upgrades the bottom scroller into an adaptive, song-aware information strip. The curated music disk now contains **209 directly playable tracks**: **73 Amiga**, **50 C64**, and **86 Atari ST** titles.

The release preserves every existing playlist path and carries forward the v1.5.4 Amiga Exact, C64, and Atari work. No SID, Paula, YM, parser, replay, or audio-engine behavior was changed for these two feature additions.

## Changes

### 1. The Great Giana Sisters — four Amiga conversions

- Adds a dedicated `tracks/amiga/giana-sisters/` folder with:
  - **Title Screen** — `title-screen.mod`
  - **Get Ready!** — `get-ready.mod`
  - **In-Game 1 – Ground** — `ingame-1-ground.mod`
  - **In-Game 2 – Cave** — `ingame-2-cave.mod`
- Integrates all four files into the production playlist, nested folder navigation, archive search, curated list titles, and existing MOD/Paula playback path.
- Adds individual museum cards with history, composition and Amiga credits, technical observations from the supplied bytes, and safe HTTPS source links.
- Distinguishes Chris Hülsbeck's underlying compositions, Thomas Lopatic's 1988 Amiga music and Beathoven Synthesizer replay, and the later ProTracker conversions distributed with the project.
- Documents the four files in `tracks/amiga/classics/provenance.json` with original archive filenames, source URLs, byte sizes, SHA-256 hashes, orders, patterns, samples, and sample-data sizes.
- Records the editorial scope in `doc/museum/amiga-track-sources.md`. The MODs are later conversions, not original BSS modules; their empty embedded titles and absent conversion credits are not replaced with guesses.
- Includes only the four verified compatible conversions. **Options** and **High Scores** are not filled with unsuitable or unverified substitutes.

### 2. Adaptive TRACK / TECH / STORY scroller

- Generates **TRACK** content from the curated title, available composer credit, active system, and current SID/HIPC subsong.
- Generates **TECH** content from actual binary metadata: module type, Paula channels, patterns, samples, SID addresses and subsong count, or YM rate, clock, and Digidrum count.
- Generates **STORY** content from the selected track's researched museum text instead of showing the same generic message for every song.
- Keeps loading, failure, and no-track states explicit and avoids describing HIPC or XM material as ProTracker-only content.
- Retains the signature sine scroller with lower amplitude, elapsed-time-based speed, seamless wrapping, and immediately readable content after a track or channel change.
- Adds native **TRACK**, **TECH**, **STORY**, and **HOLD/RUN** buttons with pressed states, accessible labels, visible keyboard focus, and touch-safe targets.
- Supports hover hold, explicit pause/resume, and `prefers-reduced-motion`; reduced-motion users can still opt into movement explicitly.
- Keeps the mobile strip bounded at 108px plus safe-area inset and prevents the canvas from growing through an indefinite flex/grid sizing loop.
- Leaves playback and emulation code unchanged.

### 3. Release documentation

- Updates `README.md` to v1.5.5 with the new Giana folder, adaptive scroller, 209-track library, validation results, and known limitations.
- Adds copy-ready GitHub release notes in `doc/releases/v1.5.5-Release-Text.md`.
- Adds this copy-ready PR description in `doc/releases/v1.5.5-PR-Text.md`.
- Keeps v1.5.4 and earlier release documents unchanged as historical records.

## Scope and boundaries

- The four Giana files are later ProTracker conversions; the browser does not claim to emulate the original Beathoven Synthesizer/BSS replay for this release.
- No conversion author is inferred from an archive directory or composer credit.
- No C64 SID, Atari YM, BRSTM, MP3, or prerecorded substitute is presented as an Amiga track.
- Public archive availability does not imply public domain, redistribution permission, or a commercial-use license. Rights remain with their respective holders.
- The scroller derives its text from existing curated and binary metadata; it does not invent historical facts or call an external generative service.
- Offline timing ratios and headless Chromium viewports are not physical-device latency, underrun, or listening-quality guarantees.
- C64/SID random-access seeking remains unavailable.
- The known pre-existing SID synthetic-corpus mismatch remains disclosed; no failing baseline was overwritten.
