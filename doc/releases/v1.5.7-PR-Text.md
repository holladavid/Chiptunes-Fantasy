# Pull Request Title

**feat: release v1.5.7 with triggered PCM scope and DSE refinements**

# Pull Request Description

## Summary

This PR prepares Chiptunes Fantasy **v1.5.7** as a visualization and presentation release. Its centerpiece is a real PCM oscilloscope: the former display-rate scalar history is replaced by audio-rate time-domain capture, stable triggering, min/max column rasterization, and a fast CRT phosphor sweep. The FFT analyzer receives a matching segmented phosphor redesign with cached static work and refresh-rate-independent motion.

The release also carries forward the post-v1.5.6 Scene-DJ/DSE refinements: slower intensity-dependent tension buildup, three improved universal effects, responsive Starfield redistribution, C64/Paula rendering repairs, a binding DSE development guide, and a custom CF pixel-chip identity for browser, iOS, and PWA use.

The curated library remains **213 tracks: 73 Amiga, 54 C64, and 86 Atari ST**. Existing playlist paths and the SID, Paula, and YM audio architectures are retained.

## Changes

### 1. Real triggered PCM oscilloscope

- Reads actual audio time-domain data from the existing master-path `AnalyserNode` using `getFloatTimeDomainData()` and a `getByteTimeDomainData()` fallback.
- Reuses a **4096-sample** capture buffer; no additional AudioWorklet messaging channel is required.
- Derives each **32 ms** window from the actual audio sample rate: **1,536 samples at 48 kHz** and **1,411 samples at 44.1 kHz** in the measured browser run.
- Removes DC using the mean of the complete analyser buffer.
- Arms a rising zero-crossing trigger with hysteresis and interpolates the crossing position to reduce horizontal waveform jitter.
- Maps all samples belonging to each pixel column through min/max ranges so narrow impulses are not discarded by point sampling.
- Uses fixed amplitude gain and **160 quantized amplitude levels** for a deliberate retro readout.
- Draws a bright **32 ms left-to-right sweep**, incrementally burning only newly reached columns into the current-trace canvas.
- Keeps the previous completed trace on a separate memory canvas at reduced opacity, with **420 ms** time-based persistence and a blank retrace.
- Preserves current/memory images and active-sweep PCM/raster coherence across resize; `clear()` resets capture, sweep, persistence, and particle state.
- Reuses typed arrays and caps the spark pool at **64** entries.
- Replaces shadow blur on hundreds of waveform subpaths with a broad transparent outer stroke; soft shadow remains only on the small beam head.

### 2. Redesigned FFT phosphor analyzer

- Uses **48 logarithmically spaced bars from 45 Hz to 12 kHz** with the existing **4096-point FFT / 2,048-bin** analyser.
- Mixes bin average and peak information with a moderate high-frequency lift instead of flattening all bars through the removed square-root level lift.
- Adds system-specific palettes, segmented LED bars, an unlit LED matrix, measurement guides, and a logarithmic frequency ruler.
- Samples analyser data at **30 Hz**, reuses the analyser array and preallocated bar/range arrays, and rebuilds the cached static grid only when layout or system changes.
- Makes attack/release smoothing, **0.42-second peak hold**, and peak gravity dependent on elapsed time rather than display refresh rate.

### 3. Scene DJ and DSE refinements

#### Tension and exact musical events

- Slows tension accumulation for moderate passages while allowing full-board channel energy and active beats to accelerate it.
- Adds a **55% buildup threshold** and an intensity-dependent buildup hold before climax, retaining hysteresis on the return to playing.
- Keeps **playing** and **buildup** visibly distinct instead of letting moderate tracks jump too quickly into overdrive.
- Counts only physical audio channels for analogue energy; the C64's fourth telemetry slot remains SID write-rate data, not phantom channel energy.
- Routes exact beat events separately from the decaying beat envelope so discrete pattern changes do not retrigger every frame.

#### Universal DSEs

- **Starfield:** adds three exact-beat-switched warp/vortex patterns, deterministic recycling, aliased trails, and system-specific treatment. Resizes redistribute the existing star field immediately across widescreen and rotated mobile viewports, avoiding clusters and black unused regions while retaining the same instance.
- **Copperbars:** adds three formations switched only on exact fourth-beat events, alternating beat direction, buildup/climax-specific punch and twist, and a dedicated afterglow state.
- **TrackPresenter:** introduces aliased 5×7 bitmap typography, fourth-beat layout changes, state-sensitive palettes/motion, and deterministic rotation-safe layouts.
- `void` remains outside the universal-DSE refinement scope.

#### C64 and Paula repairs

- Scales the C64 sunset's horizon offset from its rasterized sun radius, preventing narrow portrait buffers from placing every visible sun row below the horizon.
- Gives Paula silicon-floor instances their own copies of cached moiré/grid canvases so later resize operations cannot deform shared cache snapshots or other viewport formats.

### 4. DSE development contract and app identity

- Expands `doc/concepts/dse_development_rules.md` into a concrete implementation and acceptance contract covering:
  - macro/micro music response and exact beat events;
  - per-system palettes, low internal resolutions, integer rasterization, and ordered-dither transitions;
  - responsive world projection, safe areas, fullscreen, and same-instance rotation;
  - deterministic random resources, instance ownership, caching, and bounded degradation;
  - automated tests, visual evidence, production-browser checks, and a definition of done.
- Adds an original CF pixel-chip SVG favicon and local PNG exports.
- Integrates an opaque **180×180 Apple touch icon**, **192×192 / 512×512** regular PWA icons, and a **512×512 maskable** icon through `index.html` and `manifest.json`.

### 5. Release documentation

- Updates `README.md` to v1.5.7 with the real PCM architecture, FFT design, DSE scope, validation, and limits.
- Adds copy-ready GitHub PR and release documents for v1.5.7.
- Leaves v1.5.6 and earlier release documents unchanged as historical records.

## Scope and boundaries

- This PR changes visualization, Scene-DJ/DSE behavior, app artwork, and documentation. It does **not** replace the SID, Paula, or YM synthesis engines or add prerecorded audio.
- The oscilloscope's display refresh rate and audio capture resolution are separate concerns: a 30/60/120 Hz canvas can still display thousands of real PCM samples per sweep.
- The scope is a triggered visual instrument, not a calibrated laboratory measurement device or a spectral/phase analysis guarantee.
- Historical constraints continue to apply to individual DSEs. Arbitrary Scene-DJ layer combinations remain intentionally fantastical.
- The focused test result is not a claim that the complete historical test suite is newly all green. The known pre-existing SID synthetic-corpus mismatch remains disclosed, and C64/SID random-access seeking remains unavailable.
- Browser render timings and headless/mobile-viewport checks do not guarantee physical-device frame rates, audio-underrun freedom, or every Safari/PWA fullscreen variant.
- No new tracks or changes to music licensing/provenance are included.
