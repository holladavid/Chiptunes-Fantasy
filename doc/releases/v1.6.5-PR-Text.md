## Summary

Version 1.6.5 delivers a comprehensive **Living Silicon hardware audit, visual engine performance overhaul, and historical metadata fact-check** across all three computer pillars (**Commodore 64**, **Amiga**, and **Atari ST**). It introduces **cross-folder transport navigation**, eliminates **iOS Safari mobile search zooming**, corrects **DIP pinouts and hardware filter polarities**, and optimizes the **CRT shader, oscilloscope, FFT analyzer, and CRT glitch pipelines** for high-refresh-rate (120 Hz+) displays.

## Changes

### 1. Living Silicon Hardware Verification & Pinout Accuracy (`js/ui/silicon/*`, `css/style.css`)

- **MOS 6581 SID (`sid-6581.js`, `sid-meter.js`, `base-chip.js`):**
  - Repaired broken Voice 2 bypass bus trace (`sig-osc2-byp` stopped at `x=212, y=48`).
  - Eliminated C64 font clipping on Master VCA and VCF mode labels; rerouted `sig-master-out` inside the chip package leadframe (`y=43` to `y=30`) avoiding top pin numbers.
  - Added a bus-write hold timer (`0.045s`) so address/data/CS pin flashes remain visible on 60/120 Hz displays.
  - Aligned VCF frequency curve logarithmically to the true 6581 S-curve with smooth quadratic Bézier curves.
  - Centered voice meters symmetrically in `SidMeter` (`x = 22 + v * 56`), extended logarithmic history frame to 162px, added a hold timer to the `D418` indicator, and inverted label contrast on active glow (`.sid-meter-digi.is-active + .sid-meter-digi-label`).
  - Added quantization-based dirty checking to `updateBusFlow()` and `updatePinGlow()` in `BaseChip`, slashing SVG DOM mutations by ~85%, and corrected PAL clock readout to `0.985 MHz`.
- **MOS 8364 Paula (`paula-8364.js`):**
  - Corrected physical DIP-48 pin assignments to match authentic MOS specifications: audio outputs route to **Pin 31 (`AUDA` Left)** and **Pin 30 (`AUDB` Right)** instead of joystick POT pins 32/33; clock routes to **Pin 28 (`CCK` 3.55 MHz)** instead of data bit D3; DMA request routes to **Pin 12 (`DMAL`)** instead of interrupt pin 15.
  - Uncrossed left and right traces cleanly on the die cavity without jumper arcs.
  - Added missing packet animation paths on RCA outputs (`sig-rca-l`, `sig-rca-r`).
  - Centered ZOH scopes vertically and normalized phase advance to frame delta-time (`dtScale`), preventing double-speed animation on 120 Hz displays.
  - Added dirty-checking across volume bars, DMA LEDs, and filter response curves.
- **Yamaha YM2149F (`ym-2149.js`):**
  - Corrected clock input pin to authentic **Pin 22 (`CLOCK`)** instead of Port A Pin 21.
  - Fixed broken SVG path geometry on Hardware Envelope Shape 11 (`\---`) in `buildEnvelopeShapePath()`.
  - Resolved text overflow in the Sinc-FIR filter box and added missing board output packet animations (`boardFinalOut`).
  - Normalized square-wave phases and digidrum hold timer to frame delta-time (`dtScale`).
  - Implemented dirty-checking across all mixer gates, noise bars, envelope bars, DAC levels, and block opacities.

### 2. Visual Engine Performance & CRT Shader Optimization (`js/visuals/components/*`)

- **Row-Batched FFT Analyzer (`fft-analyzer.js`):**
  - Batched VFD/phosphor segment rendering by row rather than per bar, reducing Canvas `fillStyle` switches from ~2,000 to ~60 per frame (~30× reduction in Canvas state overhead).
  - Eliminated DC-offset leakage into 45 Hz sub-bass bins by sampling Catmull-Rom interpolation strictly from bin 1+.
  - Clamped treble sub-bin sampling steps to 24, reducing Catmull-Rom evaluations by 4× on high frequencies.
  - Repositioned the Amiga dotted accent line above the spectrum to avoid intersecting frequency scale labels.
- **Trigger-Locked Oscilloscope (`oscilloscope.js`):**
  - Fixed long-term 8-bit `destination-out` alpha ghosting with an automatic idle cleanup pass after 1.25 s of silence, resetting `hasCurrentTrace` and `hasMemory` to stop redundant `drawImage` blits during pause.
  - Converted the cross-correlation trigger to an amplitude-normalized **Mean Squared Error (-MSE)** lock over 64 fixed points, providing identical trigger stability across mobile portrait and 4K viewports.
  - Cached draw-style states to eliminate thousands of string parsing operations per frame.
  - Reused endpoint samples in `buildSweepRaster()` (`vStart = vEnd`) for a 33% reduction in Catmull-Rom evaluations.
- **3-Phase CRT Glitch & Degauss Collapse (`crt-glitch.js`):**
  - Upgraded transition glitch into a realistic 3-phase CRT power cycle synchronized with the 300 ms theme blackout: horizontal slice degauss sine wave and H-sync tearing, chromatic ghost split, and an intense electron beam collapse with a central phosphor bloom that automatically adopts the target system's phosphor accent color at the 50% cycle peak.
  - Added graceful, non-flashing fade fallback when `prefers-reduced-motion: reduce` is detected.
- **CRT Shadow Mask Shader (`crt-shadow-mask.js`):**
  - Phase-aligned scanlines (3.0 px) with phosphor dot cells to completely eliminate 6 px moiré drift.
  - Cached WebGL pipeline states, viewport, and uniforms to prevent redundant setup calls on every rendered frame.

### 3. UI, Transport & Mobile Ergonomics (`js/app.js`, `css/style.css`, `js/ui/*`)

- **Full-Library Transport Stepping (`js/app.js`):**
  - `INJECT ROM` now reliably starts Track #1 if triggered from the root directory or an empty folder view.
  - `Next` (`BUS >`) and `Previous` (`< MEM`) now cycle seamlessly across the computer's entire library across folder boundaries (with automatic breadcrumb and selection synchronization) instead of remaining trapped in the active folder.
- **Compact Mobile Search Input (`css/style.css`):**
  - Replaced the wide `Press Start 2P` font in `#track-search` on mobile screens with compact `VT323` at 16px, allowing `"TRACK, PATH, COMPOSER"` to fit comfortably without clipping while strictly preventing unwanted iOS Safari auto-zooming.
- **Fullscreen UI Refinement (`fullscreen-ui.js`):**
  - Streamlined transport button labels to eliminate brackets on the main playback bar (`RESUME BUS` vs `[ RESUME BUS ]`), preventing text clipping on narrow 375px mobile screens.
  - Cached DOM element lookups and bypassed timeline updates when the fullscreen bar is hidden.
- **Now Playing Console Optimization (`now-playing-console.js`, `css/style.css`, `js/app.js`):**
  - Added `cleanMetaValue()` sanitization to prevent raw parser strings like `"Unknown"` or `"None"` from blocking fallbacks.
  - Expanded `.now-playing-meta-hardware` to span 2 columns in the fullscreen metadata grid for balanced layout.
  - Bypassed 15 Hz DOM updates when the expanded console is hidden in windowed mode.
