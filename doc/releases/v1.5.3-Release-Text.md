# GitHub Release Title

**Chiptunes Fantasy v1.5.3 — YM2149 Production Timing, Measured Resampling and Browser Acceptance**

# GitHub Release Description

**Von Nerds für Nerds:** v1.5.3 completes the bounded Atari-ST/YM2149 release program. The Exact worklet now combines YM3/YM5/YM6 transport, cycle-stamped digital synthesis, YM6 effect timing, linear channel summing and a measured two-stage output chain. Exact remains a software model with documented evidence boundaries; Fantasy and unrelated C64/Amiga DSP paths are not retuned by this release.

## YM6 effects and format transport

- Digidrum, SID-Voice, Sinus-SID and Sync-Buzzer commands use two independent effect slots.
- MFP timing follows `2457600 / predivisor / timerCount` on the 2 MHz YM timeline. Continuous effects retain phase, repeated Digidrum commands retrigger, and finished effects return to current register levels.
- YM3!, YM3b, YM5! and YM6! parsing covers interleaved and frame-serial register dumps, metadata, signed/unsigned/4-bit samples and stored loop points.
- Playback, seeking, UI duration and Media Session timing use the parsed player rate and loop metadata.

## Linear output and measured two-stage resampling

The three YM voices sum linearly with one fixed level-preserving scale. The former additional bus compression and `tanh` output saturation are removed. The declared output model uses a 15.9 kHz low-pass and 25 Hz high-pass; neither that model nor the −1.5 dB/step DAC mapping is presented as a measured Atari-mainboard calibration.

The final resampler uses two cascaded 256-phase Kaiser-windowed-sinc stages while retaining the 20 kHz passband and 96 dB design target:

| Output rate | Stage taps | Group delay | Worst stopband-start response |
|---:|---:|---:|---:|
| 44.1 kHz | 181 + 493 | 1.439558 ms | −99.463 dB |
| 48 kHz | 163 + 297 | 0.811333 ms | −102.999 dB |
| 96 kHz | 73 + 87 | 0.129979 ms | −98.939 dB |

Register-derived periods and fixed volume levels are cached on writes. The FIR inner loop is unrolled without changing its accumulation order. These changes address the 44.1 kHz real-time bottleneck without lowering the filter target.

## Validation

- Focused YM core, production, transport and resampler tests pass, including block-size independence at 44.1/48/96 kHz.
- Full suite: 265 tests, 203 passing, 1 known SID-corpus failure and 61 skipped tests; 17 of the skips are HIP tests blocked by the missing fixture.
- All 73 supplied Atari tracks are parsed by the corpus tests; all ten nonzero stored loop points are exercised through the production worklet.
- Sixty-second production renders of `WINGLEV1.YM`, `Turrican2_TheDesertRocks.YM` and `GOLDRUN.YM` are bit-identical across repeated fresh runs and contain zero non-finite samples.
- Measured sandbox processing time is approximately 25–28% of rendered audio duration in the documented long-render cases. These figures are not physical-device benchmarks.
- Real Chromium AudioWorklet playback covers 44.1 and 48 kHz at 1440 × 1000 desktop and 390 × 844 mobile-emulation viewports. Contexts run and advance, analyser data is finite and audible-path activity is non-zero, and no local 404 or AudioWorklet error was observed.
- One mobile-emulation run had an external `fonts.gstatic.com` connection failure. It was traced to the webfont, not a local resource or audio module; a separate mobile repetition was error-free.
- Paula and YM visualizer mocks/assertions are repaired. Living Silicon now displays linear summing and the implemented resampling/output stages.

Detailed measurements and reproduction commands are in `doc/specs/emulation/atari/ym-measurement-harness.md` and `doc/specs/emulation/atari/ym-performance-browser.md`.

## Known limitations

- The supplied archive omitted `test/helpers/sid-corpus.mjs`. The reconstructed helper reproduces silence, pulse, saw, triangle and triangle+pulse exactly against the archived raw/trace/WAV hashes. Noise, hard-sync/ring, filter-sweep, `$D418` and TEST-reset stimuli still differ. The SID baseline fixtures were not overwritten, and the affected pre-existing SID regression remains open.
- The independent HIP register-sink helper is present, but `tracks/amiga/Wings_Of_Death-Title.hip` is absent. Consequently the HIP tests skip, and the 600-tick oracle comparison has not actually run.
- Headless Chromium with a mobile viewport is not a physical phone. No controlled listening test or claim of glitch-free loudspeaker output on reference devices is made.
- Real YM2149 DAC variation and Atari-mainboard calibration remain future measurement work. Self-generated hashes are regression anchors, not hardware truth references.
- Background playback remains subject to browser, mobile OS and power-management policy.

## Run locally

Serve the source tree over HTTP(S); ES modules and `AudioWorklet` loading are not intended for `file://` URLs.

```bash
npx serve .
# or
python3 -m http.server 8080
```

Open the shown local URL, enter through the boot screen, select **ATARI ST**, and inject a YM track from the archive.
