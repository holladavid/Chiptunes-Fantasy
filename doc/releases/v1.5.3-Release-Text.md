# GitHub Release Description

**Von Nerds für Nerds:** v1.5.3 completes the bounded Atari-ST/YM2149 release program and expands the music disk into a carefully curated **86-track Atari library**. The Exact worklet now combines YM3/YM5/YM6 transport, deterministic 2 MHz digital synthesis, YM6 effect timing, linear channel summing, and a measured two-stage output chain. A new technical deep dive documents the complete architecture and its evidence boundaries.

No MP3s or prerecorded audio are used. Exact remains a software model, not a claim of universal physical-chip or mainboard equivalence; the artistic Atari cores and unrelated C64/Amiga DSP paths are not retuned by this release.

## Highlights

- Refined YM2149 Exact digital behavior, deterministic reset, and raw measurement harness.
- MFP-derived YM6 timing for Digidrum, SID-Voice, Sinus-SID, and Sync-Buzzer.
- Correct YM3!/YM3b/YM5!/YM6! parsing, player rates, stored loops, seeking, and Media Session timing.
- Linear three-voice summing and measured two-stage 256-phase Kaiser-Sinc resampling.
- **86 curated tracks**, including **13 new highlights**, nested folders, concise list labels, and revised museum texts.
- A dedicated **Atari ST Technical Deep Dive** covering implementation, measurements, and limitations.

## YM2149 Exact: digital behavior and YM6 effects

The raw offline harness accepts cycle-stamped register events and exposes deterministic raw samples, internal state traces, CSV, and IEEE-float32 WAV without hidden output processing. The production core advances tone, shared 17-bit noise, the 5-bit hardware envelope, mixer gates, and DAC levels on the 2 MHz YM timeline.

R13 envelope writes now select the correct initial level and preserve a full first step; `$FF` leaves the running envelope untouched. Fixed volume zero is silent. Restarting a track is bit-identical to a fresh worklet, track changes clear inherited state, and stop/resume preserves digital and transport state.

Two independent YM6 effect slots use:

```text
2457600 / predivisor / timerCount
```

Integer phase accumulation maps that timing onto the 2 MHz YM timeline. Continuous effects retain phase, repeated Digidrum commands retrigger, and completed effects return to current register levels. Sample and effect levels use the selected voice's YM/DAC path rather than a fictitious native PCM channel.

## Formats, transport, and loops

The parser supports YM3!, YM3b, YM5!, and YM6! files, including:

- interleaved and frame-serial register dumps;
- signed, unsigned, and already-4-bit Digidrum data;
- validated headers, metadata strings, sample bounds, and end markers;
- parsed player-rate and loop metadata.

Playback, seeking, UI duration, and Media Session position use the same player-rate conversion. Tracks with stored loop points return to their own `loopFrame` instead of always restarting at frame zero.

The production `ym-exact` processor remains a fixed-2-MHz register-dump player. It does not execute MC68000 replay code, emulate the complete MFP, or play SNDH files.

## Linear output and measured two-stage resampling

The three YM voices sum linearly with one fixed level-preserving scale. The former additional bus compression and `tanh` output saturation are not part of the Exact path. The declared output model uses a linear 15.9 kHz low-pass and 25 Hz high-pass; neither that model nor the DAC table is presented as a measured Atari-mainboard calibration.

The final resampler uses two cascaded 256-phase Kaiser-windowed-sinc stages with an intermediate rate of four times the host rate, a 20 kHz requested passband, and a 96 dB design target:

| Output rate | Stage taps | Constant group delay | Worst stopband-start response |
|---:|---:|---:|---:|
| 44.1 kHz | 181 + 493 | 1.439558 ms | −99.463 dB |
| 48 kHz | 163 + 297 | 0.811333 ms | −102.999 dB |
| 96 kHz | 73 + 87 | 0.129979 ms | −98.939 dB |

Register-derived periods and fixed volume levels are cached on writes. The FIR inner loop is unrolled without changing its accumulation order. These changes address the former 44.1 kHz real-time bottleneck without lowering the filter target.

The 13 new files were unpacked from their LH5 source archives without changing register data, embedded metadata, or Digidrums. Exact source archives, inner filenames, provenance, and rights boundaries are documented in `tracks/atari/SOURCES.md`; no new rights to historical music files are claimed.

## Validation

- **Focused Atari selection:** 48 tests — 48 passed, 0 failed.
- **Full suite:** 273 tests — 211 passed, 1 known pre-existing SID-corpus failure, 61 skipped.
- All **86** curated YM files parse as 2 MHz / 50 Hz register dumps; every track has unique logical/source paths and a museum card.
- All **12** nonzero stored loop points are exercised through the production worklet.
- Production output is deterministic and independent of audio block size at 44.1, 48, and 96 kHz.
- Sixty-second production renders of `WINGLEV1.YM`, `Turrican2_TheDesertRocks.YM`, and `GOLDRUN.YM` are bit-identical across repeated fresh runs and contain zero non-finite samples.
- Measured sandbox processing time is approximately 25–28% of rendered audio duration in the documented long-render cases. These figures are not physical-device benchmarks.
- Real Chromium AudioWorklet playback covers 44.1 and 48 kHz at 1440 × 1000 desktop and 390 × 844 mobile-emulation viewports. Contexts run and advance, analyser data is finite and nonzero, and no local 404 or AudioWorklet error was observed.
- Nested Atari navigation, `[UP] ..`, short labels, museum cards, and representative YM3!/YM5!/YM6! and Digidrum playback were checked in Chromium.
- One earlier mobile-emulation run had an external `fonts.gstatic.com` connection failure. It was traced to the webfont, not a local resource or audio module; a separate mobile repetition was error-free.

## Known limitations

- The supplied archive omitted `test/helpers/sid-corpus.mjs`. The reconstructed helper reproduces silence, pulse, saw, triangle, and triangle+pulse exactly against the archived raw/trace/WAV hashes. Noise, hard-sync/ring, filter-sweep, `$D418`, and TEST-reset stimuli still differ. The SID baseline fixtures were not overwritten, and the affected pre-existing SID regression remains open.
- The independent HIP register-sink helper is present, but `tracks/amiga/Wings_Of_Death-Title.hip` is absent. Seventeen HIP tests therefore skip, and the 600-tick oracle comparison has not run.
- Headless Chromium with a mobile viewport is not a physical phone. No controlled listening test or guarantee of glitch-free loudspeaker output on reference devices is made.
- Real YM2149 DAC variation and Atari-mainboard calibration remain future measurement work. Self-generated hashes are regression anchors, not hardware truth references.
- The Exact Atari path does not provide MC68000/MFP/SNDH replay, Atari-STE DMA audio, or arbitrary non-2-MHz production playback.
- Seeking jumps to a register frame and resets YM6 effect progress; it does not reconstruct every possible historical chip/filter state by replaying from frame zero.
- Background playback remains subject to browser, mobile OS, and power-management policy.

## Run locally

Serve the source tree over HTTP(S); ES modules and `AudioWorklet` loading are not intended for `file://` URLs.

```bash
npx serve .
# or
python3 -m http.server 8080
```

Open the shown local URL, enter through the boot screen, select **ATARI ST**, and browse the curated game and demo-scene folders. Local YM files can also be injected through the existing player interface.
