## Summary

This release builds on v1.6.0 with a focused **UI & responsive layout overhaul**, **Scene-DJ engine timing/lifecycle fixes** (with headless Node test coverage), **nearest-neighbor HiDPI canvas & resize synchronization**, and targeted visual/compliance fixes across three **Amiga OCS DSEs** (`AmigaRetroSunset`, `AmigaBoingBall`, `KefrensCheckerboard`).

## Changes

### 1. Responsive UI, Theme Tokens & Fullscreen Stage Cockpit

- **Markup & HUD structure (`index.html`, `js/ui/hud-debugger.js`):** Updated boot screen header to `V1.6.1`, restored `<div class="system-tabs">` inside `#player-panel` (replacing a stray duplicate `#demo-canvas` tag), added `#fs-track-time`, `#fs-progress-bar`, `#now-playing-progress` hooks, standardized `[ FULL ]` / `[ EXIT ]`, and closed a stray column wrapper in Amiga `updateChipHUD`.
- **Theme tokens, responsive Command Deck & fullscreen cleanup (`css/style.css`):**
  - Unified theme-metric typography variables (`--font-size-xs/sm/base/title/prose/grid`), improved C64/Atari CRT contrast, fixed Amiga active-tab rainbow `::after` indicators, added CRT scrollbars, and prioritized `image-rendering: pixelated` after `crisp-edges`.
  - Scoped the 3-column Command Deck to `>= 2200px` widescreen, kept a 2-column workbench up to `2199px`, positioned open `.silicon-guide` panels beside `.silicon-chassis` on `1300px–2199px`, contained mobile HUDs inside `#visual-zone`, refined mobile portrait/landscape breakpoints (`<= 1024×580`), raised `#eco-overlay` `z-index: 50`, and cleared stage bottom borders / `#000000` page bleed in native and pseudo-fullscreen.
- **Interactive seeking & stage sync (`js/app.js`, `js/ui/fullscreen-ui.js`, `js/ui/now-playing-console.js`):**
  - Added pointer scrubbing on `#fs-progress-bar` and `#now-playing-progress` for seekable Amiga/Atari tracks and kept `#time-current` / `#progress-slider` synced on `seekToFrame()`.
  - Unified fullscreen track copy (including `[SUB x/y]` indicator), removed duplicate desktop copy in `#fs-ui-bar`, kept `#fs-ui-bar` visible on `:focus-within`, reset subsong index on track switch, and woke stage overlay on playback state transitions.
- **Canvas resize observation (`js/visuals/visualizer.js`):** Added `ResizeObserver` plus `fullscreenchange` / `webkitfullscreenchange` listeners, capped HiDPI scaling at `1..2x` / `1920px`, and guarded `0px` canvas resizes and negative/non-finite `dt`.

### 2. Scene-DJ Engine Hardening & Headless Integration

- **`StageManager` (`js/visuals/dj/stage-manager.js`):** Added per-cache `beatStarted` latching and peak metric buffering across skipped PAL ticks on >50 Hz displays, skipped canvas allocation/rendering/blitting for `idle` DSEs, added `invalidateCache()` and `restartedStarting` detection, fixed `oneshot` cleanup and onstage `duration` tracking, restricted `getMaxClimaxHoldTime()` to active visible `managed` DSEs, and added `createCanvas` injection.
- **`SetlistManager` (`js/visuals/dj/setlist-manager.js`):** Sequenced opaque `background`/`floor` transitions (`queuedTransitions`) so outgoing DSEs finish fading out before incoming scenes start, deferred swaps during `climax` and `afterglow`, enforced `maxInstances` in `manageSwaps()`, cleared queued transitions on `forceSystemChange()`, and avoided wasteful `idle` pre-fills on system switch.
- **`TrackMonitor` & `TensionManager` (`js/visuals/dj/track-monitor.js`, `js/visuals/dj/tension-manager.js`):** Switched channel smoothing to clamped `[0, 1]` exponential integration, sanitized `dt` (`<= 0.1s`), normalized `TensionManager` energy momentum to `dt`, preserved `buildup` 45% hysteresis across brief quiet dips, and added Atari YM2149 tone/volume novelty sniffing.
- **`SceneDJ` & rules (`js/visuals/scene-dj.js`, `doc/concepts/dse_development_rules.md`):** Added `createCanvas` injection, forwarded system retro dimensions in `resize()`, deferred `TrackPresenter` starts until `isPlaying` is active, and synchronized `doc/concepts/dse_development_rules.md` with engine guarantees and v1.6.0+ DSE standards.

### 3. Amiga OCS DSE Fixes

- **`AmigaRetroSunset` (`js/visuals/dse/amiga/retro-sunset.js`):** Removed the unmasked `y = horizon` shimmer beam, raised mountain valley endpoints (`y: 6`, `minMh` guard, rimlight at `drawH >= 2`), rebuilt the water reflection into `1 px` `1/z` Copper scanlines with wobbled mirrored mountain silhouettes and scattered glints, fixed even-radius climax solar slit parity, preserved afterglow colors in `stopping`, and guarded seagull respawns, sky last-band rounding, `lastBeatCount = -1`, `idle` resets, and narrow Bayer dithering.
- **`AmigaBoingBall` (`js/visuals/dse/amiga/boing-ball.js`):** Removed the red/gold rectangular floor reflection box beneath the checkerboard shadow, added integer viewport flooring and `[0..w, 0..h]` polygon/silhouette edge clipping, fixed `starting`/`stopping` transition timing against unreset `stateTime`, reset transient/beat state on `idle`, tightened OCS shading ramps to `12` steps, and cooled specular highlights in `afterglow`.
- **`KefrensCheckerboard` (`js/visuals/dse/amiga/kefrens-checkerboard.js`):** Replaced the `RetroSunset`-coupled sun-track cone with background-independent roaming Copper disco hotspots (single + dual crossing hotspots in `buildup`/`climax`) tinted from each active Copper palette, preserved afterglow colors in `stopping`, fixed Bayer frontier column indexing, initialized `lastBeatCount = -1`, reset accumulators on `idle`, promoted Beveled Slabs consistently on `climax`, and replaced per-segment PRNG glints with deterministic `tileGlintHash`.

### 4. Automated Test Coverage

- Added `test/dj-engine-lifecycle.test.mjs` (oneshot cleanup, `climaxHold` filtering, 60/120 Hz tension parity, `buildup` hysteresis, Atari novelty, `forceSystemChange`, idle-skip/cache invalidation, climax/afterglow swap deferral, opaque vs. foreground/void sequencing, and `maxInstances`).
- Added `test/scene-dj-integration.test.mjs` (headless end-to-end `SceneDJ` run using real `dseRegistry` across C64/Amiga/Atari, macro-state arcs, portrait/ultrawide rotation, zero/NaN guards, beatless playback, and deferred presenter activation).
- Expanded `test/graded-beat-detection.test.mjs` and `test/graded-beat-routing.test.mjs` for `[0, 1]` channel-smoothing bounds, >50 Hz PAL beat latching, and zero/NaN guards.
