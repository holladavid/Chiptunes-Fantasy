# GitHub Pull Request — v1.6.6

Chiptunes Fantasy v1.6.6 — Interactive CRT & Scope Calibration Deck, Linear-Light WebGL CRT Pipeline & 100 Hz-Capped Oscilloscope

## Summary

Version 1.6.6 introduces a live **CRT & Phosphor Oscilloscope Calibration Deck** (`[ CRT / SCOPE ]`, shortcut `C`) backed by a persistent settings store, an **A/B factory-comparison bypass** (shortcut `B`), a **physically modeled linear-light WebGL CRT shadow-mask shader**, and a **configurable, framerate-independent (100 Hz-capped) oscilloscope engine** with layer-batched drawing and level-normalized trigger locking.

## Changes

### 1. Persistent Display Calibration Store & UI Deck (`js/visuals/display-settings.js`, `js/ui/display-setup-dialog.js`, `index.html`, `css/style.css`, `js/app.js`, `js/visuals/visualizer.js`)

- **`DisplaySettingsStore` (`js/visuals/display-settings.js`):**
  - Persists CRT and Oscilloscope settings in `localStorage` under `chiptunes-fantasy.display-settings.v1` with corruption/quota error resilience.
  - Enforces strict numeric clamping (`CRT_BOUNDS`, `OSC_BOUNDS`) and enum validation (`CRT_QUALITIES`, `CRT_MASK_TYPES`, `OSC_BEAM_MODES`, `OSC_TRIGGER_MODES`, `OSC_PHOSPHOR_TINTS`).
  - Adds monitor presets (`default`, `auto`, `rgb`, `composite`, `grille`, `delta`) with system-aware `AUTO SYS` mapping (`c64 -> composite`, `amiga -> rgb`, `atari -> grille`) that preserves the selected GPU quality tier across preset switches and system changes.
  - Implements non-destructive **A/B bypass** (`setBypassed`), individual/global resets, CRT WebGL availability state tracking, and reason-tagged subscriber notifications (`crt`, `osc`, `bypass`, `availability`, `reset`).
- **`DisplaySetupDialog` (`js/ui/display-setup-dialog.js`, `index.html`, `css/style.css`):**
  - Adds `[ CRT / SCOPE ]` (`#btn-display-setup`) alongside `[ FULL ]` inside `.fs-stage-actions` and anchors `<aside id="display-setup-dialog">` dynamically below `#playback-bar` via `ResizeObserver`.
  - Exposes CRT presets, `MASK` (`SLOT` / `DELTA` / `GRILLE`), `SCAN` (`1X` / `2X`), `GPU` (`LOW` / `MED` / `HIGH`), 9 CRT calibration sliders (`MASK PITCH`, `MASK DEPTH`, `SCANLINES`, `BEAM BLUR`, `HALATION`, `R/B DRIFT`, `TUBE CURVE`, `VIGNETTE`, `CONTRAST`), and 8 Oscilloscope controls (`BEAM FX`, `TRIGGER`, `PHOSPHOR`, `V/DIV GAIN`, `TIMEBASE`, `PERSISTENCE`, `PHOSPHOR GLOW`, `GRATICULE`).
  - Supports double-click per-slider factory reset, `[ RESET ]`, `[ A/B ]` live comparison banner, and automatic `HIGH ONLY` disabling of `HALATION` when quality is `< high` or CSS fallback status notices when WebGL CRT is inactive.
  - Adapts across all viewports: 2-column desktop rack (no tabs at `>= 1050×581`), 3-column CRT / 2-column Scope slider grids at `>= 1500×680`, right-docked floating rack inside fullscreen stages (`updateHostMount()`), pinned top stage + bottom sheet on mobile portrait (`<= 800px`), and 50/50 side-by-side live split on mobile landscape (`<= 1024×580`).
- **App & Keyboard Integration (`js/app.js`, `js/visuals/visualizer.js`):**
  - Wires `C` (toggle setup deck), `B` (toggle A/B bypass while open), and `Escape` (close setup deck before exiting pseudo-fullscreen), while allowing global shortcuts when focus rests on `<input type="range|checkbox|radio|button">`.
  - Suspends mouse idle auto-hide while the setup deck is open, keeps `#fs-ui-bar` subtly reachable (`opacity: 0.78`) in windowed mode, closes the deck on Eco Mode entry, and syncs `AUTO SYS` profiles on theme/power-cycle transitions.

### 2. Linear-Light WebGL CRT Shadow Mask Engine (`js/visuals/components/crt-shadow-mask.js`)

- **Linear-Light Pipeline & Geometry:**
  - Switches sampling and blending to linear light (Gamma 2.0 `c * c` fetch and `sqrt` output) and replaces the screen quad with a seamless fullscreen triangle using `highp` vertex coordinates (`v_px`) to avoid `gl_FragCoord` `mediump` drift on mobile GPUs `>1000 px`.
  - Adds SDF rounded tube bounds (`cornerRadius`) with 1-px anti-aliasing, barrel `curvature` `[x, y]`, $\cos^4$ `vignette`, radial R/B `convergence` drift, horizontal 2-tap bilinear beam bandwidth (`beamBlur`), and Jimenez interleaved gradient noise dithering (`±0.5 LSB`).
- **Analytical Pixel-Snapped Masks & Two-Pass FBO Halation:**
  - Implements exact 1-px box-filtered `slotMask`, `deltaMask` (hexagonal triad lattice), and `grilleMask` snapped to integer multiples of 3 (6 for `delta`) in device pixels and normalized via `meanTransmission` for zero brightness loss and zero moiré at any DPR.
  - Adds a 4:1 box-filtered low-res FBO pass (`createGlow`, `renderGlow`) stored as `sqrt()` and sampled via 5 smooth taps on `'high'` quality, automatically falling back to `'medium'` if RTT framebuffers are unsupported.
  - Simulates beam-current spot blooming (`MASK_DEPTH_AT_FULL_BEAM`, `SCAN_DEPTH_AT_FULL_BEAM`) and raised-cosine scanlines (`scanlineRows: 1 | 2`).
- **Runtime API & Safety Guards:**
  - Adds `setOptions(options)` (recompiling shaders only on `quality` changes), `dispose()`, `PRESETS` (`rgb`, `composite`, `grille`), `DEFAULT_OPTIONS`, `HIGH_FLOAT` precision validation, `MAX_TEXTURE_SIZE` and tainted-canvas guards, and `failIfMajorPerformanceCaveat: !allowSoftwareGL`.

### 3. Configurable, Framerate-Independent Phosphor Oscilloscope (`js/visuals/components/oscilloscope.js`)

- **100 Hz Simulation Cap & Framerate Independence:**
  - Decouples `simulate(dt, ...)` from `compose(ctx, ...)` with a `MIN_STEP_SECONDS = 0.01` step accumulator and `slowFade`-proportional memory deposition so persistence and brightness remain identical across 60 Hz, 120 Hz, 144 Hz, and 240 Hz monitors.
- **Trigger & Rendering Performance:**
  - Level-normalizes Schmitt trigger slope and `-MSE` correlation (`invPeak`, `invPower`, `TRIGGER_HYSTERESIS = 0.0008` floor + 8% peak) so quiet and mid-level signals lock reliably; adds `triggerMode: 'auto' | 'free'`.
  - Switches trace drawing to layer-batched passes (`colColor`, `colAlphaHalo`, `colAlphaCore`, `colAlphaTurn`, `colAlphaPlateau`, `colSegTop`, `colSpan` typed arrays), cutting canvas state switches in half with pixel-identical output, and adds a `dwellLut` lookup table eliminating per-column `Math.pow()`.
  - Centers optical bloom vertically on trace segments (`segTop + (span - 1) * 0.5`) and upgrades `parseColor()` to handle `#rgb/#rgba/#rrggbb/#rrggbbaa`, `rgb()/rgba()`, and CSS named/HSL colors.
- **Live Calibration API:**
  - Supports constructor options (`createCanvas` injection included) and runtime `setOptions()` / `getOptions()` for `gain`, `timeWindowMs` (with `fftSize - 64` headroom guard), `persistence`, `bloom`, `graticule`, `beamMode` (`sparks`, `spot`, `off`), `triggerMode`, and `phosphorTint` (`system`, `p31`, `p11`, `amber`).

### 4. Automated Unit Tests (`test/display-settings.test.mjs`, `test/oscilloscope.test.mjs`)

- Added `test/display-settings.test.mjs` (5 tests): defaults & broken-storage resilience, bounds clamping & persistence, `AUTO SYS` resolution & quality retention, `toCrtMaskOptions` curvature mapping, and A/B bypass / reset / typed subscriptions.
