# GitHub Release Title

**Chiptunes Fantasy v1.5.2 — Living Silicon, Real SID Activity, Original-Recording Calibration**

# GitHub Release Description

**Von Nerds für Nerds:** v1.5.2 turns the C64 Living Silicon panel into a working demoscene instrument and completes a series of bounded Exact-SID refinements. Chiptunes Fantasy still executes and synthesizes original C64, Amiga, and Atari music binaries in real time—no MP3s and no prerecorded-audio playback.

## New: SID Activity for Living Silicon

The C64 die view now includes a responsive activity instrument driven by real Exact/Fantasy telemetry:

- **Three 16-segment voice meters** show normalized envelope activity—not loudness or CPU load.
- **GATE indicators, short peak holds, and actual ADSR phases** make short notes and retrigger behavior visible.
- **True register writes/second** count repeated same-value writes and writes that occur between display frames.
- **A logarithmic 48-column bus history** keeps ordinary music drivers and faster register routines readable on the same scale.
- **Independent `$D418` indication** preserves the distinction between total register traffic and digi-oriented volume-register activity.

The instrument uses preallocated state and dirty-checked updates. Its responsive rail remains available on desktop, laptop, and mobile instead of disappearing with the secondary diagnostic flanks.

Panel titles now clearly distinguish **MOS 6581 R3 Exact** from **SID Fantasy Studio**. Model parameters are labelled as simulation values rather than physical sensor measurements.

## Exact refinement: Wizball short-GATE behavior

A supplied original-C64 recording of *Wizball*'s high-score melody, Subsong 7, exposed missing short bubble/chirp attacks in the former Exact path.

The MOS 6581 R3 envelope now restarts its 15-bit rate phase on a resolved rising GATE, resets the exponential divider, and clears zero hold. Release preserves running counters; `TEST` does not restart the attack phase. The existing two-clock GATE pipeline and zero-level underflow protection remain intact.

In the measured 5.5–10.5-second passage, all **21 short voice-2 GATE attacks** now reach envelope level **255**. Previously, 20 of those attacks remained at level 0 or 1. The restored sequence follows the supplied recording for this examined case.

This is bounded original-recording calibration—not a claim of universal ADSR accuracy, coverage of every 6581 revision, or general superiority over another emulator.

## Exact refinement: Giana's `$50` “angel voice”

*The Great Giana Sisters* high-score melody, Subsong 2, revealed a weak Exact-path combined-waveform voice around the 30-second passage.

The hardware-oriented 6581 path now uses an independently measured, phase-indexed `$50` triangle-plus-pulse transfer model with **257 precomputed 12-bit anchors** and allocation-free primitive interpolation. Other combined selectors retain their wired-AND baseline. Fantasy DSP remains separate and unchanged by this Exact calibration.

## Correct display time for arbitrary SID play rates

The displayed C64 timeline now uses an independent 50 Hz accumulator. Tracks whose music routines are dispatched by CIA or rates other than 50 Hz receive a meaningful elapsed-time display without changing audio, CPU/CIA scheduling, or subsong timing.

## Foundation carried forward

Version 1.5.2 retains the completed SID refinement program and player integration from v1.5.1:

- deterministic measurement and regression infrastructure;
- measured Kaiser-Sinc resampling and parameterized output coupling;
- MOS 6581 R3 digital, filter, and mixer models with documented evidence boundaries;
- bounded CPU/CIA timing corrections;
- the artistic Fantasy stereo studio path;
- Media Session transport, metadata, artwork, and supported seeking controls;
- zero-sized Canvas frame protection;
- zero-level ADSR underflow protection for short GATE pulses.

Exact targets **MOS 6581 R3**. A separate hardware-oriented **CSG 8580** model remains future work. External libsidplayfp/reSIDfp observations are used only as black-box references; no implementation code or internal tables were imported.

## Validation

- **34 focused SID tests:** 34 passed, 0 failed.
- **10 deterministic SID baseline cases:** passed and bit-identical after the Living Silicon changes.
- **Original Wizball upload:** Subsong 7 selected through the UI and checked with Exact and Fantasy.
- **Responsive Chromium checks:** 1440 px desktop, 1280 px laptop, and 390 px mobile; active telemetry, no horizontal overflow, and no page/console errors.
- **Cold start:** all voices `IDLE`, zero active meter segments, zero bus traffic.
- **Full suite without optional GC instrumentation:** 200 tests — 150 passed, 44 skipped, 6 failed.

The six failures are the same unrelated pre-existing HIP/Amberstar/Paula/YM cases. No additional failing test was introduced.

## Known limitations

- Exact CSG 8580 emulation remains separate future work.
- Combined-waveform analog behavior and chip-specific variation still require further physical-hardware evidence before stronger authenticity claims are justified.
- Exact calibration and validation claims are limited to the documented Wizball and Giana cases.
- C64/SID system seeking remains unavailable because reliable random-access seeking is not implemented.
- Background playback remains subject to browser, mobile OS, and power-management policy.
- Six unrelated pre-existing HIP/Amberstar/Paula/YM test failures remain open.

## Run locally

Serve the extracted source tree over HTTP(S); ES modules and `AudioWorklet` loading are not intended to run through `file://` URLs.

```bash
npx serve .
# or
python3 -m http.server 8080
```

Open the shown local URL, enter through the boot screen, select a system, and inject a track from the archive.
