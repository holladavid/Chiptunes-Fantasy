## Summary

Version 1.6.8 elevates the visual craftsmanship of the **Atari ST** pillar across **9 DSEs and sprite assets** (`AtariFlatShadedTrio`, `AtariLaserGrid`, `AtariPondRipples`, `AtariLineRibbons`, `AtariBobs`, `AtariRetroSunset`, `WireframeMorph`, `YmSiliconBg`, and `ik-fighter-sprites.js`), upgrades **`TrackPresenter` (`v3.2.0`)** with rock-steady centered typography and a 9-bit Timer-B Atari ST banner (`4.0 s` overlay duration), hardens **`hardware-constraints.js`** with 1:1 Midpoint circle fill/outline parity and NaN/bounds guards, codifies multi-technique hardware raster and C2P buffer rules in **`doc/concepts/dse_development_rules.md`**, and expands strict fake-canvas test coverage (`test/atari-bobs.test.mjs`, `test/atari-pond-ripples.test.mjs`, `test/ym-silicon-bg.test.mjs`).

### 3. Shared Hardware Constraints & DSE Architecture Spec (`js/visuals/utils/hardware-constraints.js`, `doc/concepts/dse_development_rules.md`)

- **`js/visuals/utils/hardware-constraints.js`:**
  - Hardened `rgbToHex`, `getNearestC64Color`, `quantizeAmiga12Bit`, `quantizeAtari9Bit`, `applyOrderedDitherFade`, `drawAliasedLine`, `fillAliasedPolygon`, and `fillAliasedPolygonClipped` against `NaN`/`Infinity`, missing contexts, and out-of-range inputs.
  - Rewrote `fillAliasedCircle` as an exact odd-span integer Midpoint rasterizer matching `drawAliasedCircleOutline` 1:1 (zero `Math.sqrt`), deduplicated cardinal/diagonal outline plots, added optional `clipRect` support + `fillAliasedCircleClipped` / `drawAliasedCircleOutlineClipped` wrappers, and optimized `transparentDither` loops with `x += 2` parity stepping.
- **`doc/concepts/dse_development_rules.md`:**
  - Codified system-authentic raster discipline: C64 (*Hires*, *Multicolor*, *Raster-Splits/FLI*, OLED luminance ramps), Amiga OCS/ECS (16–32 bitplane subpalettes, *EHB*, *HAM6*, *Mid-Scanline Copper / Copper-Chunky*), and Atari ST (`<= 16` colors/scanline per DSE layer, *Timer-B* splits, *Spectrum-512*, mandatory `#fcfcfc` max via `quantizeAtari9Bit`).
  - Documented *Bitplane-Index-Addition / Shade-Bobs*, prohibited `getImageData()`, restricted `putImageData()` solely to preallocated chunky/C2P index buffers verified against system palettes, and updated fake-canvas test verification criteria.
